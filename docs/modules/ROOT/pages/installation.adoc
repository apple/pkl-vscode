= Installation

The extension is distributed as a Visual Studio Extension (_.vsix_) file.
To install the extension,

1. download the latest version of the _.vsix_ file from https://github.com/apple/pkl-vscode/releases/latest/
2. follow https://code.visualstudio.com/docs/editor/extension-gallery#_install-from-a-vsix[Install from a VSIX] in the VS Code docs.

To confirm that the installation succeeded, open a _.pkl_ file and verify that syntax highlighting works.

== Pkl Language Server

Language features such as code completion, hover documentation, and diagnostics are provided by the xref:lsp:ROOT:index.adoc[Pkl Language Server] (`pkl-lsp`), version 0.9.0 or higher.
The extension does not bundle it, and looks for it in this order:

1. The path configured in the `pkl.lsp.path` setting.
2. A `pkl-lsp` executable in `PATH` (for example, one installed with `brew install pkl-lsp`).
3. A `pkl-lsp` executable previously downloaded by the extension into `~/.pkl/editor-support/lsp-distributions/`.

If `pkl-lsp` cannot be found, the extension offers to download the native executable for the current platform from https://github.com/apple/pkl-lsp/releases[GitHub].
Executables downloaded this way are checked for updates when the extension starts.

Pre-built executables are available for macOS (aarch64), Linux (amd64 and aarch64), and Windows (amd64).
On other platforms, see xref:lsp:ROOT:installation.adoc[Installation] in the Pkl Language Server documentation, and either place `pkl-lsp` in `PATH` or configure `pkl.lsp.path`.
